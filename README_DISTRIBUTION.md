# Mahika Dictionary Application

## About

Mahika is a Vietnamese-English dictionary application with text-to-speech capabilities and keyboard navigation support for visually impaired users.

## System Requirements

- Windows 10/11 (64-bit)
- No Python installation required

## Installation

1. Download the application zip file
2. Extract all files to a folder on your computer
3. Run `Mahika.exe` to start the application

## Features

- English to Vietnamese dictionary lookup
- Text-to-speech in both Vietnamese and English
- Keyboard navigation optimized for accessibility
- Audio feedback for all interactions
- OCR text recognition
- File reading capabilities

## Keyboard Controls

### Global Navigation

- `Shift + H`: Go back to previous page
- `Shift + L`: Go forward to next page
- `Shift + 1`: Go to File List page
- `Shift + 2`: Go to Word List page
- `Shift + 3`: Go to Word Detail page

### Word List Page

- `L`: Move to next word
- `H`: Move to previous word
- `J`: Enter word detail for selected word
- `S`: Stop current audio playback

### Word Detail Page

- `R`: Read word definition aloud
- `J` / `Down Arrow`: Scroll down
- `K` / `Up Arrow`: Scroll up
- `I`: Read navigation instructions
- `S`: Stop current audio playback

### Login Page

- `Enter`: Login with current credentials

## Audio Features

- Automatic pronunciation of English words
- Vietnamese translation read aloud
- Audio instructions and feedback
- Background TTS with immediate response

## File Size and Performance

- Application size: ~200-500MB (includes all dependencies)
- First startup may be slower (10-30 seconds)
- Subsequent startups are faster
- No internet connection required for basic functionality

## Troubleshooting

### Application won't start

- Make sure all files from the zip are extracted
- Run as Administrator if needed
- Check Windows Defender/Antivirus settings

### Audio not working

- Check system volume and audio device
- Ensure Windows Speech Platform is installed
- Try restarting the application

### Performance issues

- Close other applications to free memory
- Ensure adequate disk space (1GB free recommended)
- Update Windows audio drivers

## Privacy

- No data is collected or transmitted
- All processing is done locally on your computer
- Internet connection only used for enhanced dictionary features
